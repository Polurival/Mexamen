# Задачи для прогона локальных моделей (те же, что у облачного ассистента)

Каждая задача — холодный старт, без уточнений, в отдельном worktree. Модель выбирается в Continue (Cursor → панель Continue → селектор модели), режим указан ниже.

## Задача 1 — генерация фичи (День 1), режим Agent

Worktree: `../Mexamen-local-day1` (от `2ba764c`: фичи статистики по темам ещё нет, `CLAUDE.md` v2 скопирован, `.continue/` скопирован).

Промпт (дословно из `docs/rules-experiment/README.md`):

> Помоги улучшить статистику в приложении: на экране StatsScreen нужно показывать количество пройденных вопросов и количество верных ответов для каждой из тем вопросов. На FlashcardScreen на карточке с правильным ответом, нужно показывать сколько раз этот вопрос юзер уже проходил и сколько раз дал верный ответ. Тоже самое для QuizScreen, точнее в ResultScreen - для каждого вопроса показать сколько раз был пройден, и количество верных ответов

Оценка — чеклист из `docs/rules-experiment/README.md` (компиляция, тесты, логика в `domain/`, stateless Screen, нет второго стора, испанский UI, DI/App.kt).

## Что фиксировать на каждый прогон

| Поле | Как мерить |
|---|---|
| С первого раза? | да / нет / частично (что пришлось подсказать) |
| Качество кода | чеклист задачи + `git diff --stat` |
| Скорость | время от отправки до финального ответа (секундомер), tok/s из `bench-results.txt` |
| Понимание контекста | правильные файлы, соблюдены ли правила (слои, испанский, Koin) |
