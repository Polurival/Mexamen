## Как устроен loop

```
для каждой issue #5..#24 по порядку:
  date → профиль по метке: bug → bug-fix, иначе → feature (в прогоне 1 — general-purpose с тем же чеклистом)
  агент: gh issue view N → правка → compileAndroidMain + compileKotlinWasmJs + testAndroidHostTest → отчёт (без коммита)
  оркестратор: независимый verify (те же 3 задачи Gradle, число тестов из XML)
  rules-reviewer: diff vs CLAUDE.md + пункты «Сделано, когда» → PASS / FAIL (FAIL = blocker/major)
  FAIL → SendMessage тому же агенту с замечаниями → попытка 2 (счётчик «с первого раза» = ❌)
  PASS → git commit "(#N)" → строка в лог → следующая issue
```

- «С первого раза» = первый отчёт агента прошёл независимый verify **и** ревью без blocker/major.
- «Сломался» = задачу нельзя довести без человека (непонятное ТЗ, красные проверки после 3 итераций, зацикливание). Таких задач **не было ни в одном прогоне**.
- Время задачи = от `start` до коммита, включая ревью; паузы инфраструктуры вычтены. Сырые логи: [`run1.log`](run1.log), [`run2.log`](run2.log).

## Почему пропущена локальная модель

Задание просит прогнать тот же пул на локальной модели. **Пропущено сознательно**, по результатам Дня 4 ([PR #4](https://github.com/Polurival/Mexamen/pull/4), `docs/local-llm/` в ветке `local-llm-day4`):

- ноутбук без GPU, инференс только на CPU — тянет модели 1.5–3B (`qwen2.5-coder:1.5b`, `qwen2.5:3b`; `qwen3:4b` — на пределе);
- на задаче Дня 1 (фича через 9 файлов) локальная модель написала **0 строк кода**; задача Дня 2 в агентном режиме — **0 из 3** прогонов, в режиме Edit — 2 ошибки компиляции;
- индексация `@Codebase` грузила 4 ядра > 85 минут и вдвое замедляла инференс; ~3 с на одну автодополняющую подсказку;
- системный промпт Claude Code (~20k токенов) + CLAUDE.md не помещаются в рабочий контекст таких моделей, т.е. execution loop с профилями/ревьюером запустить на них нельзя в принципе.
