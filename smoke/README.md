# Smoke-тесты Mexamen (уровень 2)

Пользовательские сценарии на **физическом Android-устройстве** (USB, `adb`), без эмулятора.
Сценарии — `scenarios/S*.md`; шаги в блоке ```steps``` одинаково читаются агентом через MCP и раннером.

## Как гоняет агент (MCP)
`.mcp.json` подключает [claude-in-mobile](https://github.com/AlexGladkov/claude-in-mobile) (`npm i -g --prefix ~/.local claude-in-mobile`, бинарь `claude-in-mobile` в `PATH`). После перезапуска Claude Code в сессии появятся инструменты `mobile`; запусти `/test-all`.

## Запасной путь без MCP
```
ANDROID_SERIAL=<serial> python3 -I smoke/tools/run_smoke.py --out smoke/reports/<дата>
```
Результат: `report.md` + скриншот после каждого шага (`S<id>-<шаг>.png`). Код возврата 1, если что-то упало.

## Словарь шагов
| Шаг | Смысл |
|---|---|
| `clear` / `launch` | `pm clear` (чистая статистика) / перезапуск приложения |
| `tap: <текст>` | тап по элементу с таким text/content-desc (точное совпадение приоритетнее подстроки) |
| `tap_option: N` | N-й вариант ответа квиза |
| `expect: <текст>` / `expect_absent: <текст>` | текст есть / нет на экране (ждёт до 8 с) |
| `expect_text_value: <метка> = <значение>` | значение сразу после метки (счётчики статистики) |
| `back` | системная «назад» |
| `repeat N:` + вложенные шаги | повтор блока |

## Сценарии
S1 квиз целиком · S2 карточки · S3 статистика + сброс · S4 отмена сброса · S5 легенды.
