---
name: update-smoke
description: Сценарий «я задеплоил новую фичу — обнови smoke-сценарии и прогони всё заново». Обновляет smoke/scenarios по diff и запускает /test-all.
---

1. Определи, что изменилось: `git diff main...HEAD --stat` и `git diff main...HEAD -- composeApp/src/commonMain/kotlin/dev/polurival/mexamen/ui composeApp/src/commonMain/kotlin/dev/polurival/mexamen/App.kt`. Ищи новые/изменённые экраны, кнопки, испанские тексты, `Route`.
2. Сопоставь с `smoke/scenarios/S*.md`:
   - изменился текст/кнопка → поправь шаги существующих сценариев;
   - появился новый экран/сценарий пользователя → добавь `S<N+1>-<имя>.md` (формат — как у соседних: цель, предусловие, блок ```steps```, ожидание);
   - убрана фича → удали/перепиши сценарий.
   Тексты в шагах — **точные** испанские строки из кода. Держи сценариев 3–7.
3. Чтобы убедиться в актуальности текстов, снимай `adb shell uiautomator dump` нужного экрана (через `smoke/tools/adbx.sh dump`), а не угадывай.
4. Покажи пользователю diff сценариев (кратко), затем выполни `/test-all` и выдай единый отчёт.
